## Reproduce

Use the dedicated runtimes and test-only Playwright installation described in
the runbook; all paths below are explicit local prerequisites:

```bash
export JAVA_HOME=/path/to/java21-jdk
export WATTLY_PYTHON=/path/to/python3.12-venv/bin/python
export WATTLY_PG_BIN=/path/to/postgresql/17/bin
export NODE_PATH=/path/to/test-tools/node_modules
export PLAYWRIGHT_BROWSERS_PATH=/path/to/test-tools/browsers
export WATTLY_STACK_PROOF="$PWD/.local/new-v15-proof"
./mvnw -q clean
"$WATTLY_PYTHON" scripts/verify-forecast-stack.py
```

The actual proof is under ignored `.local/v15-main-sync-20261019/stack-v1/` in
the PR worktree. The runner creates and stops its own PostgreSQL/Spring/browser
processes and transient timer. It overrides database URLs and reads collector
snapshots without altering the collector. No persistent database, Flyway history
or checksum was changed. Private test environment files remain excluded from Git.
